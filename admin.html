Inside

Admin

已是管理员。隐私文章会在浏览器中用 AES-GCM 解密。可在下方生成密文。

Encrypt

把正文 HTML/纯文字粘贴下面，用管理员密码加密后，把密文写进文章 front matter 的 private_cipher，并加上标签 隐私。
正文可以留空。网页源码里只会有密文。

Posts

用 GitHub Token 直接增删改 _posts/ 里的文章。Token 只保存在本机浏览器 localStorage,不会写进博客。 权限需要 Contents: Read and write(GitHub → Settings → Developer settings → Fine-grained tokens)。
