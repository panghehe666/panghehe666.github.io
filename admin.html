你已是管理员

Private

Admin

进入管理员，查看并解密标记为「隐私」的文章。

登录 = 用密码解开仓库里的 secrets.enc.json。解不开就不是管理员，没有别的入口， 改浏览器 localStorage 也没用。

First Run

Setup

仓库里还没有密钥信封。设一个管理员密码，把 DeepSeek API Key 和 GitHub Token 一起加密进去， 之后任何设备只要输这个密码，就能同时解锁私密文章、AI 助手和文章发布，不用再单独配置任何密钥。

密码是唯一防线，也是唯一钥匙：忘了它，私密文章和信封里的密钥会一起永久丢失，没有任何找回途径。 请离线抄一份存好，不要只存在脑子里。

Inside

Admin

已解锁。私密文章会在浏览器里用 AES-GCM 解密；AI 助手与文章发布所需的密钥已从信封中取出， 无需再单独配置。关闭标签页即清除（除非登录时勾了「记住此设备」）。

Secrets

DeepSeek API Key 与 GitHub Token 用管理员密码加密后，存在仓库的 secrets.enc.json 里。 仓库公开也不要紧——没有密码，它就是一段废 Base64。登录之后这两项会自动供给 AI 助手与发布流程， 换设备不用再手填。

尚未读取

Migrate

换了新密码之后，用旧密码加密的私密文章会解不开。这里用旧密码解开、再用当前会话的新密钥重新加密， 然后提交回仓库。已经是新格式的文章会自动跳过。只在换密码后跑一次。 


      



      

        
Encrypt

        

          把正文 HTML/纯文字粘贴下面，用管理员密码加密后，把密文写进文章 front matter 的 private_cipher，并加上标签 隐私。

          正文可以留空。网页源码里只会有密文。
        

        
        
        
        
        

      


      
      

        
Posts

        

          用 GitHub Token 直接增删改 _posts/ 里的文章。登录管理员后会自动使用密钥信封里的 Token，这里通常不用填。
          只有在信封里没配 Token 时才需要手填（手填的值只存在本机浏览器 localStorage，不会写进博客）。
          权限需要 Contents: Read and write，且只授权这一个仓库（GitHub → Settings → Developer settings → Fine-grained tokens）。
