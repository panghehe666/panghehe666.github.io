密钥配置(一次性)

把 DeepSeek Key 与 GitHub Token 用你的「管理员密码」加密,写进站点。之后只要登录管理员,AI 助手和文章增删改都会自动就绪,不用再配置。明文永不上传。

· 加密用 AES-GCM(PBKDF2 750000 轮),密文写在 js/site-secrets.js
· 只有输入正确管理员密码才能解开;密码错了生成的密文永远解不开,重来一次即可
